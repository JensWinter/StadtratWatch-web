# Sicherheitslücken melden

Du hast eine Sicherheitslücke in StadtratWatch gefunden? Danke, dass du sie uns mitteilst.

**Bitte melde sie vertraulich und nicht als öffentliches Issue.** Nutze dafür die private Meldung über GitHub:
[Sicherheitslücke melden](https://github.com/JensWinter/StadtratWatch-web/security/advisories/new) (im Reiter
„Security“ der Schaltfläche „Report a vulnerability“).

_Please report vulnerabilities privately via the link above, not as a public issue. Reports in English are welcome._

## Was betroffen sein kann

- die Website [www.stadtratwatch.de](https://www.stadtratwatch.de)
- die öffentliche API unter `/api/v1/`
- die Suche (Typesense) unter `typesense.unser-magdeburg.de`
- die Reichweitenmessung (Matomo) unter `matomo.unser-magdeburg.de`
- der Code in diesem Repository

## Was in die Meldung gehört

- welcher Teil betroffen ist (URL, Datei oder Schnittstelle)
- wie sich die Lücke nachvollziehen lässt
- welche Folgen du erwartest

## Was du erwarten kannst

StadtratWatch ist ein ehrenamtliches Projekt. Wir antworten so schnell wie möglich, können aber keine festen Fristen
zusagen. Eine Prämie (Bug Bounty) gibt es nicht.

Bitte greife nicht auf fremde Daten zu, verändere oder lösche keine Daten und belaste die Dienste nicht durch
Massenanfragen.
