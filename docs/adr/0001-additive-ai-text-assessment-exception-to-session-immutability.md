# Additive exception to session-data immutability for KI-Einschätzung

Session data is immutable once approved. The KI-Einschätzung effort (Wayfinder-Karte [#501](https://github.com/JensWinter/StadtratWatch-web/issues/501)) needs to retroactively add an optional `aiTextAssessment` field to already-approved `session-speeches-*.json` files — both to catch up 2026 sessions processed before the feature existed, and whenever the underlying detector is re-run on an existing speech. We decided this is allowed as a narrow, permanent exception: the write must (1) only add the single `aiTextAssessment` field, never touch any existing field, (2) come exclusively from a run of the `detect-ai-text` script, never a manual edit, and (3) land in its own commit referencing the originating Wayfinder ticket. Any other retroactive change still falls under the general immutability rule.
